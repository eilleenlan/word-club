# 小小拼字所 · Word Club

適合手機、平板與電腦的英文拼字練習網頁。使用 HTML、CSS 和 JavaScript，不需要安裝套件或付費 API。

## 使用

執行 `node server.cjs`，開啟 http://127.0.0.1:4173 。也可直接開啟 `index.html`，但瀏覽器的語音與本機紀錄支援可能不同。

選年級、難度與單元開始練習。一年級已加入四課 40 題，二年級已加入前兩課 22 題，三年級已加入前兩課 27 題，四年級已加入前四課 72 題，五年級已加入前四課 80 題；六年級已加入前四課 81 題。每次完成單元後，儲存該瀏覽器的最高「第一次答對」題數；使用額外提示、答錯或看答案的題目會加入複習。字母提示模式原本提供的首字母不算額外提示。未完成的練習不會儲存；複習成績不覆蓋完整單元的紀錄。

「綜合練習」可勾選一個或多個已學單元，支援全選及清除，顯示總題數。每輪涵蓋所選範圍的全部單字；相同英文與中文的重複項目只出一次，片語保留完整。第一、二課共 20 題，四課全選共 40 題。「打亂題目順序」控制是否隨機出題，提示難度及教材錄音規則和單課相同。未勾選單元時無法開始。

綜合練習依年級與所選單元組合保存獨立成績，不覆蓋單課紀錄。綜合錯題複習只重練當輪的錯題，不覆蓋整個範圍的成績。本年級未加入單字時，單課及同年級綜合練習沒有可出題內容，仍可使用跨年級模式複習低年級已加入的單字。

「跨年級練習」按孩子所選年級決定上限：五年級累積一至五年級、六年級累積一至六年級。進入新範圍時預設全選已加入單元，依年級分組，可自行勾選、全選或清除。沒有資料的年級明確標示尚未加入，不生成示範單字；目前已加入一年級四課、二至三年級各前兩課、四至六年級各前四課，共 322 題。重複的英文與中文意思只出一次，不同意思各自保留；片語不拆字。跨年級成績與原有單課、同年級綜合成績分開。

`words.js` 的單元以 `grade` 標記年級，同一年級內 `id` 必須唯一；不同年級可使用相同 `id`。`practice.js` 負責範圍篩選、跨年級唯一鍵、去重和成績範圍識別。新增教材後會依 grade 自動進入對應累積範圍。

發音的預設選項優先使用教材錄音：一年級 Unit 1～4 全部 40 題已使用家長提供的四個音檔分段，分別存於 `audio/unit1/` 至 `audio/unit4/`，來源見 `audio-credits.html`。去除開頭 Sight Words 及多餘尾端空白，不包含相鄰題目；原檔未更動。his／her、open／close 分開，first grade 等片語保留完整。可在「英文聲音」選單手動切換為裝置聲音。

正常速度 1 倍、慢速 0.65 倍。切換語速或聲音會立即重播目前的題目。真人錄音使用 `playbackRate` 並保留音高；合成聲音使用 `SpeechSynthesisUtterance.rate`，實際速度及品質取決於語音引擎。若英文聲音延後載入，會等待 voiceschanged，避免誤選非英文聲音。快速切換會取消過期播放。

部分裝置語音需要網路；不支援或播放失敗會顯示提示。首次自動播放若被瀏覽器阻擋，可按「聽英文發音」。教材錄音為 MP3，載入失敗時會回退到裝置英文語音並顯示提示。

答案忽略前後空白，連續空白視為一個空格；片語仍須保留單字間空格。課本寫法含大寫字母的題目（目前為 Taiwan、Taipei、Pacific Ocean、I am 與五年級 U3 國名）必須符合完整大小寫；一般小寫單字仍忽略大小寫。字母正確但大小寫錯誤時，會明確提示並讓孩子修正，列入錯題複習且不計為第一次答對。既有歷史紀錄保留，不回溯重算。

## 課本資料

`words.js` 依提供的《My School - Book 1》p.45 Appendix - Sight Words 整理，共四單元 40 題。his / her 與 open / close 分開出題，其餘片語保留完整。中文沿用課本；this / the 與 no / not 額外提供例句區別。單元中文標題為網站導覽標籤，非課本原標題。網站不包含課本掃描圖或孩子個資。

## GitHub Pages 發布

1. 在自己的 GitHub 帳號建立公開儲存庫（免費 Pages 的方式）。
2. 上傳 `index.html`、`styles.css`、`words.js`、`practice.js`、`app.js`、`speech.js`、`audio-credits.html`、`audio/unit1` 至 `audio/unit4` 資料夾和 `.nojekyll` 到儲存庫根目錄；保留音檔的相對路徑。
3. 開啟 Settings → Pages → Build and deployment，選 Deploy from a branch。
4. 選 main 分支及 / (root)，儲存並等候 GitHub 顯示網站網址。

網站使用相對路徑，支援 `https://帳號.github.io/儲存庫名稱/`。不需要執行建置。更新上述檔案並提交後，Pages 會重新發布。

原始碼儲存庫：https://github.com/eilleenlan/word-club 。正式網站：https://eilleenlan.github.io/word-club/ 。GitHub Pages 已啟用，使用 main 分支根目錄，推送更新後會自動重新發布。紀錄不跨裝置同步，同一瀏覽器共用紀錄。

## 發音回歸檢查

`node --test speech.test.cjs`：涵蓋錄音與語音選擇、正常／慢速參數、切換取消、延遲聲音載入、錄音失敗回退與自動播放阻擋。這些檢查驗證播放流程，不能取代各裝置的實際聽感測試。

`node --test practice.test.cjs`：使用僅存在測試檔中的多個年級資料，檢查五年級範圍不包含六年級、跨年級同單元編號不衝突、重複字去重、保留舊成績鍵，以及空選取與未提供教材的處理。測試資料不載入網頁。

### mountain 發音替換與單字試聽

mountain 改用本機 Microsoft Zira Desktop（en-US）匯出的英文示範 MP3：`audio/overrides/mountain.mp3`，不是教材真人錄音。預設播放不依賴裝置語音引擎，支援 1×／0.65×。原音檔保留，其他單字仍播放各課教材錄音。

「看看本課單字」可點英文按鈕試聽，也支援鍵盤操作。清單預設正常速度與音檔優先；播放訊息顯示於首頁。切換年級、模式或開始練習會取消原播放，連續點選不疊音。
