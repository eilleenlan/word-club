# 階段 1：本機學習者與個人成績摘要

本機施工基準：382e6d9。此文件記錄待驗收功能，不表示已提交、推送或部署。

## 已接入的使用流程

首次使用輸入暱稱、選擇內建動物頭像；不要求真名、帳號、電子郵件或密碼。可新增多位人物、修改暱稱與頭像，固定 ID 不變。頁首提供目前人物、切換學習者、我的成績與舊版共用紀錄。

新分頁以裝置上次選擇的人物為預設；同一分頁重新整理及在拼字／克漏字間導覽，優先保留該分頁的選擇。其他分頁切換人物不改變本頁正在作答的歸屬。選擇目前人物只關閉面板，不結束練習。進行中切換至另一人須確認，取消則保持原練習。

每輪開始時在記憶體固定 learnerId 與 completionId；整輪完成才寫入摘要。未完成的練習重新整理會丟失當輪進度，沿用既有行為。錯題再練習不覆蓋正式成績，錯題清單仍只存在當輪記憶體。

## 成績查看與隔離

- 拼字整課卡片顯示個人最佳成績；綜合範圍顯示該範圍最佳，跨年級隨機顯示上次成績。
- 克漏字介紹頁依目前範圍與題數顯示個人成績。
- 頁首「我的成績」集中顯示個人所有摘要，包含自選部分單字，不再只有儲存卻沒有查詢入口。
- 保留最佳／最近隨機規則，不提供歷次成績曲線。字母提示與完整拼字仍沿用原本共用最佳規則，未改判題政策。
- 儲存成功需等 IndexedDB 交易完成；失敗顯示未能儲存與重試按鈕。重試沿用 completionId，避免重複寫入。

## 資料庫版本 2

從版本 1 保留所有資料，只新增 summaries、completions、rotations 三個區域，各以 learnerId + id 為主鍵。人物索引與版本防護沿用階段 0。

- summaries：activity + 原範圍識別為 id，含範圍說明、total、best 或 last，以及更新時間。不同學習者、活動與範圍分開。
- completions：整輪完成收據，讓重試能去重；不包含逐題答案或錯題，尚未作為歷程介面。將來需訂定保留策略。
- rotations：每位學習者的克漏字抽題輪替，保留原本情境輪替功能；不寫回舊 localStorage。多分頁同一目標同時抽題仍可能抽到相同情境，不影響成績隔離。
- meta 的 lastLearner：裝置上次人物；sessionStorage 的 word-club-active-learner：本分頁人物，防止其他分頁切換造成重新整理後串人。
- summaries 的最佳成績在同一交易中讀取及更新，多分頁較低分不會覆蓋已保存的較高分。隨機成績採最近完成寫入；重試舊收據不重新覆蓋。

逐題 recordOutcome 持續固定拒絕。沒有啟用 events、mastery、mistakes、rewards、wardrobe 的個人資料寫入。固定目標對照表、教材、MP3 與發音例外均未修改。

## 舊資料相容性

app.js 與 cloze.js 不再寫入任何舊 localStorage 鍵。舊共用成績與情境輪替原值完整保留。舊版共用紀錄入口唯讀顯示可解析的成績；未歸屬任何孩子，不自動匯入、不清除，也不生成個人熟練度或獎勵。階段 0 的歸屬 API 未接到本階段介面。

## 失敗與限制

- 無法開啟人物儲存時，顯示錯誤並阻止匿名開始練習，不建立假人物或假儲存成功。
- 人物建立／編輯／切換失敗保留原選擇；跨分頁版本衝突需返回選擇後重試。
- 新版需由本機 HTTP 服務或正式 HTTPS 網站使用；不再支援直接以 file:// 開啟完整功能。
- 沒有備份／還原、密碼隔離或同步；清除網站資料仍可能遺失個人資料。裝扮上線前必須另完成基本備份／還原。
- 學習者編輯面板提供清除個人成績與移除人物，需確認目標暱稱及範圍；不提供清除所有人物。
- 使用動物 emoji 作為內建頭像，不同裝置的外觀可能略有不同。

## 階段 1 補充：學習者管理（待人工驗收）

「切換學習者 → 編輯」可選擇清除個人學習紀錄或移除學習者，下一頁顯示目標及實際範圍；預設焦點在取消。成功須等資料庫交易完成，失敗顯示錯誤。

- 清除僅刪除 summaries（拼字、克漏字摘要），保留人物 ID、完成收據、輪替與其他個人資料。完成收據保留以防已完成場次的重試恢復舊成績。
- 移除明確刪除人物及 summaries、completions、rotations、sessions、events、mastery、mistakes、rewards、wardrobe 中該人物的資料，並清理該人物的上次選擇。新增資料區域時必須明確更新範圍與測試。
- 兩者都不改 localStorage 舊版共用紀錄或 legacy 快照，不影響其他人物。
- 多分頁通知會終止該人物的當輪練習並刷新畫面；刪除人物後，所有成績寫入仍在資料庫交易內檢查人物存在，因此即使通知延遲也不能產生孤兒資料。無通知支援的環境會在回到分頁時檢查；儲存時仍拒絕已刪除人物。
- 不提供復原；清除後重新完成的新練習仍可產生新成績。

補充測試檔：learner-management.test.cjs。涵蓋取消、清除隔離、明確資料範圍、失敗回滾、跨分頁移除與孤兒寫入拒絕、重新整理、舊資料保留及手機／鍵盤操作。
